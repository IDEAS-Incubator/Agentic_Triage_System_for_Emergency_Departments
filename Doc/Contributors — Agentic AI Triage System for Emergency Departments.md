# Contributors

## Agentic AI Triage System for Emergency Departments

We gratefully acknowledge everyone who has contributed to the **Agentic AI Triage System for Emergency Departments**.

This is a research and engineering project focused on exploring how Large Language Models (LLMs), AI agents, Retrieval-Augmented Generation (RAG), clinical knowledge systems, and multi-agent architectures can support emergency-department triage workflows.

We believe that meaningful contributions extend beyond source code. Research, system architecture, clinical knowledge, evaluation, documentation, testing, data preparation, project management, and community support are all important to the success of this project.

# Contribution Categories

Contributors may receive credit in one or more of the following areas.

### 🧠 Research
Research methodology, literature review, experiment design, evaluation methodology, paper writing, or scientific analysis.

### 🤖 AI / LLM Engineering
LLM integration, model selection, prompt engineering, structured outputs, reasoning pipelines, model optimization, or inference.

### 🕸 Agent Architecture
Agent design, multi-agent orchestration, tool calling, planning, memory, handoffs, or agent evaluation.

### 📚 RAG / Knowledge Systems
Retrieval-Augmented Generation, embedding models, vector databases, medical knowledge bases, reranking, retrieval evaluation, or knowledge pipelines.

### 🏥 Clinical Expertise
Emergency medicine knowledge, triage workflow design, clinical requirements, medical review, clinical evaluation, or safety recommendations.

### 💻 Software Engineering
Backend, frontend, APIs, databases, infrastructure, authentication, deployment, or application architecture.

### 📊 Data Engineering
Dataset preparation, data pipelines, data cleaning, synthetic data generation, annotation, or data quality.

### 🧪 Evaluation & Testing
Benchmark development, test cases, model evaluation, hallucination testing, safety testing, regression testing, or QA.

### 🔐 AI Safety & Security
Guardrails, privacy, security testing, prompt-injection defense, access controls, responsible-AI evaluation, or risk analysis.

### 📖 Documentation
README files, tutorials, architecture documentation, API documentation, examples, diagrams, or educational materials.

### 🎨 UX / Product Design
User experience, clinical workflow interfaces, prototypes, dashboards, or product requirements.

### 📋 Project Management
Project coordination, roadmap development, issue management, contributor coordination, release planning, or community management.

### 💡 Ideas & Conceptual Contributions
Architecture proposals, feature ideas, research questions, design discussions, or other intellectual contributions.

# Contribution Levels

Contribution level may optionally be indicated for internal recognition purposes.

### Project Lead
Responsible for major project direction, architecture, research strategy, or long-term leadership.

### Core Contributor
Makes substantial and continuing contributions to important components of the project.

### Contributor
Makes meaningful contributions to code, research, documentation, testing, clinical review, data, design, or other project areas.

### Community Contributor
Contributes bug reports, discussions, feature suggestions, reviews, examples, outreach, or other community support.

Contribution level does **not** determine the value of an individual's work. It is intended only to describe the scope and continuity of participation.

# Contributor Recognition Policy

We aim to recognize contributions transparently and fairly.

A contribution may include, but is not limited to:

- Source code
- AI/LLM development
- Prompt engineering
- Agent architecture
- RAG development
- Research
- Clinical expertise
- Dataset development
- Evaluation
- Testing
- Security
- Documentation
- UX/UI design
- Project management
- Community support
- Significant ideas or architectural proposals

Contributors do not need to write code to receive project credit.

Where possible, contributions should be traceable through Git commits, pull requests, issues, documentation changes, experiment records, meeting notes, or other project artifacts.

---

# Academic and Research Credit

Contribution to the project does **not automatically imply authorship on future academic publications**.

Authorship of papers resulting from this project will be determined separately based on the requirements and contribution standards applicable to each publication.

Contributors who provide research, experimental, clinical, technical, or writing contributions to a publication may be considered for authorship according to the publication's authorship policy.

Other contributors may be acknowledged in the paper's acknowledgment section.

---

# How to Request or Update Contributor Credit

If you believe your contribution is missing or incorrectly described:

1. Open an issue titled **Contributor Credit Update**.
2. Provide your name and GitHub username.
3. Describe your contributions.
4. Include relevant commits, pull requests, issues, documents, experiments, or other supporting information.
5. Project maintainers will review the request and update this document when appropriate.
